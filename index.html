Cosa ottieni

Una presentazione vera, in un file solo

Un solo file HTML

Tutto il deck in un file autonomo. Si apre dal browser, funziona offline, lo mandi a chiunque.

Navighi con le frecce

1920×1080, frecce e spazio per scorrere, barra di avanzamento e schermo intero. Pronto per il proiettore.

Animazioni dentro

Card che appaiono una a una, frecce SVG che si disegnano, popup finali. Le riveli passo dopo passo, dal vivo.

Il tuo brand

Due colori e un font in cima al file. Cambi le variabili e il deck diventa tuo, senza toccare il resto.

Si stampa in PDF

Ti serve il PDF? Stampi dal browser e ce l'hai. Stesso file, nessun export e nessun tool in mezzo.

Gratis e open source

Licenza MIT. La skill completa vive su GitHub, con tutti i layout, le icone e il sistema di animazioni.
